STM32F072 Canable Flasher

By Cyborg Dynamics Engineering

This tool flashes the canable-fw.bin file from candleLight-fw v2.0, available at:
https://github.com/candle-usb/candleLight_fw/releases/tag/v2.0

Note: For reliable operation, please use Google Chrome. WebUSB is not consistently supported in other browsers.
